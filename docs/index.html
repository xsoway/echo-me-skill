What it is

An honest digital mirror

Most attempts to "digitize yourself" either hallucinate a persona from nothing, or dump raw transcripts without structure. echo-me-skill avoids both.

Core concepts

Two layers, one voice

🧠

Self Memory

What you know and are. Experiences, values, habits, important memories, relationships, growth trajectory.

🗣️

Persona

How you respond. Speaking style, emotional patterns, decision patterns, social behavior — labels turned into concrete behavioral rules.

🔄

Correction layer

Your conversational corrections land immediately and take priority over prior conclusions. The mirror evolves with you.

⚖️

Two-layer resolution

Resolve Persona first (how to reply), then Self Memory (whether the reply is true to you).

Quick start

Run it in minutes

Requires Python >=3.9 and uv.

# 1. Install dependencies
$ uv sync --extra dev

# 2. Create your first self (Step A–E in SKILL.md)
#    A) profile intake  B) import material  C–E) analyze, preview, write

# 3. Validate package structure
$ python3 scripts/validate_skill_package.py .
# → PASS: echo-me-skill package contract

# 4. Run tests and lint
$ uv run pytest -q          # → 20 passed
$ uv run ruff check tools tests scripts   # → All checks passed

Safety & boundaries

Your data stays yours

✓ No fabricated content

Built only from your raw material or explicitly stated info; gaps are asked about, never invented.

✓ Material never enters the repo

Chats, photos and personal data land only in gitignored .claude/skills/{slug}/memories/.

✓ Local only

Parsers do local file parsing — no web scraping, no unauthorized network actions.

✓ Honest validation

A PASS on package validation proves completeness, not model behavior; real model eval is separate and explicit.
