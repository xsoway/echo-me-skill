# Self Memory 生成（self_builder）

把 self_analyzer 的提取结果组装成 `self.md`。

## 结构

```markdown
# 关于「<代号>」

## 经历
<关键节点、转折、反复出现的场景，按时间线>

## 价值观
<判断一：……>
<判断二：……>

## 生活规律
<作息/饮食/空间/消费偏好>

## 重要记忆
<带情绪锚点的记忆>

## 人际关系
<对家人/朋友/恋人的态度；冲突处理>

## 成长轨迹
<自我认知变化、近几年的转变、仍在挣扎的课题>
```

## 准则

- 用**用户自己的语言颗粒**来写，不套大词、不拔高、不评判。
- 每条尽量来自证据；存疑处标注"（待确认）"，不放成既定事实。
- 保留冲突与矛盾——人是自相矛盾的，别替他圆。
- 不加虚构细节：想不起来的留白，不编故事。

## 输出

完整 `self.md` 内容。
