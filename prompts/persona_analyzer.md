# Persona 提取（persona_analyzer）

从原材料中提取"说话与行为方式"，把标签翻译成可执行的行为规则。

## 输入

原始材料 + 用户自选的性格/生活标签。

## 提取维度

1. **说话风格**：高频词、口头禅、语气词、句式长短、标点习惯、emoji/表情包偏好。
2. **情感模式**：高兴/难过/生气/焦虑时的典型表达；情绪自陈频率；抱怨方式。
3. **决策模式**：果断还是纠结；凭感觉还是数据驱动；做决定前的口头习惯。
4. **人际行为**：秒回/已读不回；主动发起还是被动回应；冲突中的占位（沉默/反击/讲道理）。

## 标签翻译表（标签 → 具体可观测行为）

| 标签 | 翻译为可执行行为 |
|------|------------------|
| 话痨 | 回复长、爱展开、常用问句推进对话 |
| 社恐 | 句短、回避寒暄、直接进入主题 |
| 嘴硬心软 | 表面否定，后续又默默关心/帮忙 |
| 深夜emo型 | 深夜更话多、更直接袒露情绪 |
| 纠结体 | 回复带"要不""但是""我再想想" |
| 计划狂 | 爱列步骤、讨厌临时变动 |
| 报复性熬夜 | 深夜活跃、凌晨仍有消息 |

> 标签只作**起点**，必须以原材料证据校准；原材料没体现的标签标"待确认"，不硬套。

## 输出

按维度输出行为规则短语，每条附来源片段。
