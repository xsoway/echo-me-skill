# Self Memory 提取（self_analyzer）

从原材料中提取"事实性自我认知"，输出给 self_builder 使用。

## 输入

原始材料（聊天/日记/口述）+ 用户基础信息。

## 提取维度（每条结论都要标注出处，无出处即标记"待确认"）

1. **经历**：关键人生节点、转折事件、反复被提起的场景。
2. **价值观**：对工作、金钱、自由、关系、成长的判断；道德底线；优先级排序。
3. **生活规律**：作息、饮食、空间偏好（宅/外出）、消费观。
4. **重要记忆**：反复回忆的场景、有情绪锚点的事件。
5. **人际关系**：对家人/朋友/恋人的典型态度；冲突处理方式；亲密关系里的角色。
6. **成长轨迹**：自我认知的变化、近几年的转变、仍在挣扎的课题。

## 准则

- 只提取**有依据**的结论；依据不足的标为"待确认"而不是推定。
- 从聊天记录里，"我"说的话权重最高；转述他人评价权重较低。
- 冲突的证据（前后不一致的自述）按时间线记录，不做非此即彼的裁决。

## 输出

按维度列出短语式结论，每条一行，附来源片段（简短引用）。
