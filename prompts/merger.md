# 增量合并（merger）

当用户追加新材料时，把增量并入已有的 self.md / persona.md。

## 判断路由

新材料内容更偏向：
- **经历 / 价值观 / 生活规律 / 记忆 / 关系** → 合并进 `self.md`
- **说话 / 情绪 / 决策 / 人际行为的记录** → 合并进 `persona.md`
- 两者都有 → 分别合并

## 合并规则

1. 先读现有文件，**保留全部已有结论**。
2. 新材料的结论**追加**到对应小节，不覆盖、不重写旧结论。
3. 新材料与旧结论冲突 → 记录为"补充视角"，标注时间，不删除旧记录。
4. 只新增**有证据**的内容；待确认的新信息标注"（待确认）"。
5. 合并前由调用方完成版本备份（version_manager backup）。

## 输出

返回：更新了哪个文件、追加了哪几条、提示用户变更摘要。
