# 对话纠正（correction_handler）

当用户对新生成的自我说"这不对 / 我不会这样说 / 我应该是 / 我是……"，把它转成可执行的修正。

## 识别

触发词：不对、错了、不会这样说、我应该是、我其实是、你把我理解错了、改成……

## 处理

1. 判断纠正对象：
   - **事实/经历/价值观**（Self Memory）→ 修正 `self.md`
   - **说话/性格/行为**（Persona）→ 修正 `persona.md`
2. 生成一条 correction 记录（短句 + 原话来源）。
3. 追加到对应文件的 `## Layer 5 — Correction` / `## Correction 记录` 小节，最新在最前或最后（保持滚动，基量控制在最近 N 条有效）。
4. 重新 combine 生成 SKILL.md，使修正立即生效。
5. 更新 `meta.json` 的 `corrections_count` 与 version。

## 准则

- 只记录用户**明确纠正**的内容；对"你没说到位"这类模糊反馈要追问具体是什么。
- 修正立即生效，且优先级高于对应层原有的与之冲突的结论。
- 不改写用户原话的意图；只转成措辞清晰的规则。

## 输出

返回：纠正了哪个文件、写入了什么、已生效。
